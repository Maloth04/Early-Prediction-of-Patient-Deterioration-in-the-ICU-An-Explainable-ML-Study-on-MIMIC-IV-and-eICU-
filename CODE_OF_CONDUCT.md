# Code of conduct

## In short

Be decent. Assume the other person is trying to get something right.

## Expected

- Engage with the work rather than the person.
- Welcome disagreement about methods and figures. A well-argued objection to a
  reported number is the most valuable contribution this repository can receive, and
  it is not an attack.
- Accept correction gracefully, and offer it the same way.

## Not accepted

Harassment, personal attacks, discriminatory language, publishing others' private
information, and sustained disruption.

Clinical data deserves particular care: do not post patient-level data, or anything
derived from it that could identify an individual, in an issue, a pull request or a
comment, even as an example.

## Enforcement

Report concerns to the repository owner through a private security advisory or by
email. Reports are handled confidentially. Responses range from a warning to a
permanent ban from the repository.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.
